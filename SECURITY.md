# Trust boundaries

AssetParity compares supplied observations; it does not authenticate them by itself. The controlled testnet pilot uses disposable accounts and a self-issued test asset. Review tooling has no signing endpoint. Keep the local service on loopback and protect SQLite evidence files according to the sensitivity of imported data.

Do not publish production identities, customer information or private keys in an issue. Use GitHub private security reporting if enabled; otherwise provide a minimal impact description without secrets.
